# Gaurav Saini — Full-Stack Developer Portfolio

Private portfolio website for Gaurav Saini. It presents full-stack development services, website projects, experience, technical skills, and contact options.

## Main features

- Cinematic animated homepage
- Responsive About, Projects, Services, and Contact pages
- Supabase-backed project and inquiry management
- Password-protected admin panel
- Email delivery through Resend
- WhatsApp contact flow
- SEO metadata, sitemap, structured data, and `llms.txt`

## Technology

- Next.js and React
- Tailwind CSS
- GSAP and Framer Motion
- Supabase
- Resend
- Vercel Analytics
